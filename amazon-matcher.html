Amazon → Tiller Matcher

Matches Amazon charges in your Tiller sheet to the items you bought, for the MetaData column. Everything is processed on this device only.

1 · Get your Amazon order data

  1. Open Amazon's data request page and choose Your Orders, then submit.
  2. Confirm the request from Amazon's email. The download link arrives by email, from a few hours to a few days later.
  3. Download the file (a .zip is fine, no need to unzip).
Open Amazon "Request Your Data" page

Instant alternative on a PC: the free Amazon Order History Reporter Chrome extension exports a CSV this app also reads.

3 · Paste your Tiller rows

In Excel, select a block of rows including the header row (at least Date, Description and Amount; include MetaData to keep existing values). Copy, and paste here.

Copy a continuous block of rows with no filter applied, since you'll paste the results back into the same rows.

4 · Results

Load the Amazon file and paste Tiller rows to see matches.

Then click the MetaData cell of the first row you copied (the row under the header) and paste. Every copied row gets a value: the matched items, or its existing MetaData if it wasn't an Amazon charge. "Check" rows matched, but another order had the same amount, so glance at those.
